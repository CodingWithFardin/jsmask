# jsmask

Redact secrets in objects and strings by key and pattern.

```
import { maskText, maskObject } from "./index.js";
```

Node 18 or newer, ESM only. No dependencies.

Files: `index.js`, `index.test.js`, `package.json`.

Tests: `index.test.js`. A change that breaks one is usually the wrong change.
